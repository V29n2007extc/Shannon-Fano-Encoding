# Shannon-Fano Compressed Text Transmission

## Project Description

This MATLAB-based project demonstrates lossless text compression
and transmission using the Shannon-Fano coding technique.

## Technologies Used

- MATLAB
- Shannon-Fano Coding
- Digital Communication

## Features

- Original text input
- Character frequency calculation
- Shannon-Fano code generation
- Text compression
- Compressed data transmission
- Data decoding
- Transmission verification

## Working

Original Text
↓
Frequency Calculation
↓
Shannon-Fano Encoding
↓
Compressed Data
↓
Transmission
↓
Received Data
↓
Shannon-Fano Decoding
↓
Decoded Text
↓
Verification

## Result

The original text is successfully reconstructed after decoding,
demonstrating lossless data transmission.
